# NORDLYS — Follow the Light. Find the Wild.

Premium Nordic wilderness travel site for fjords, highlands, islands, and polar nights across Norway, Iceland, the Faroes, and Finnish Lapland.

## Stack

- Next.js 16 (App Router) + TypeScript
- React 19
- Tailwind CSS 4
- Motion

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Vercel-ready (`npm run build` passes). Connect the GitHub repo in Vercel and deploy with default Next.js settings.
